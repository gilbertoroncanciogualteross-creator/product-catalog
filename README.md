# Product Catalog

My first React project split into components. It's a simple catalog of gaming gear (keyboards, mice, headsets) using fixed data, styled with Tailwind.

Live: https://productcatalogg.netlify.app/

## Run it

npm install
npm run dev

## Notes

I built this to practice components, props and rendering lists with `.map()`. Products without stock show an "Out of stock" badge, and the list shows a message if it's empty.

Next step: a cart, so I can practice state.
